# open-weightモデルによる収集範囲の拡張

週次ジョブは別のDBではなく `src/data/events.ts` の公開イベントを読み、共演アーティスト候補を作ります。会場、地域、イベントのジャンル、主催者名と主催者URLもモデルの判断材料に含めます。

ローカルの open-weight モデルが最大5組を選びます。スクリプトは候補名と根拠イベントIDが元データに実在する場合だけ `discoveryArtistKeywords` に追加し、入力・出力トークン数とモデルの理由をレポートします。確認された入力切り詰め上限に近い出力や、生成上限に達した出力は採用しません。未レビューPRがある間は次回の実行をスキップします。公開イベントは変更せず、PRも自動マージしません。

初回PRでは、open-weightの候補名をCodexが公式サイトで別途確認したうえで、2件の公式バンド情報源も追加しています。以降の定期モデルPRは探索語を提案し、公式URLを発明して登録することはありません。現在のイベントデータには複数回登場する未登録の主催者URLがほとんどなく、会場スケジュールURLもないためです。主催者・会場・共演関係は候補の根拠としてレポートに残します。

実装PRをマージした後、Ubuntuのcontrol checkoutから週次タイマーを登録します。

```sh
ops/ubuntu/install-watchlist-expansion.sh
```

毎週月曜08:00 JSTに起動し、開始時刻には最大20分のばらつきを加えます。手動実行は次のコマンドです。

```sh
ops/ubuntu/run-watchlist-expansion.sh
```

生成されたPRは通常どおり人間が確認・マージします。
