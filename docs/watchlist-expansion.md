# 国内アーティスト共演者の探索レポート

週次ジョブは `src/data/events.ts` の公開イベントを読みます。候補抽出では `isInternational=false` を国内公演の根拠として利用します。これはイベントの属性であり、出演者一組ごとの国籍・ジャンルを保証するものではありません。

予定公演のうち前365日から先180日までを対象に、メタル、ハードロック、ラウド、ハードコア等のジャンルが付いた共演イベントから既存の探索キーワードに含まれない出演名義を集計します。同一日・都道府県・会場で重複したデータはまとめます。レポートには出現回数と根拠イベントを載せます。候補名義はバンドと断定しません。

このジョブはモデルを呼び出さず、`watchTargets.ts` やイベントデータを変更しません。候補一覧に変化がある場合だけ、レポートを含むPRを作成します。人間が対象ジャンル・アーティストを判断し、探索語の変更を別途決めます。来日アーティストは引き続き主催者・チケット・会場等の情報源から広く収集し、個別名を固定監視対象へ自動追加しません。

実行レポートとログはUbuntuサーバの `state/watchlist-expansion-<日時>.md` と `.log` に保存されます。未レビューPRがある間は重複PRを作りません。同じ候補一覧も繰り返しPRにしません。

手動実行:

```sh
ops/ubuntu/run-watchlist-expansion.sh
```;
