# Metals Calendar ロードマップ

## Vision

Metals Calendar は、日本国内のメタル、ラウドロック、メタルコア、ハードコアなどのライブや、海外アーティストの来日公演を見つけやすくするイベント検索・発見サービスです。

単なるライブ情報一覧ではなく、次の流れを支援することを目指します。

1. ライブを知る
2. アーティストや公演に興味を持つ
3. 日程、会場、公式情報を確認する
4. チケット販売サイトへ進む
5. 実際にライブへ行く

長期的には、リスナーにとって便利なイベント発見サービスであると同時に、アーティスト、プロモーター、レーベル、ライブハウス、フェス、チケット販売事業者に対して、測定可能な送客価値を提供できるメディアを目指します。

まずは Metals Calendar を、日本のメタル・ラウド系ライブを探すときに自然に使われる場所にすることを優先します。他ジャンルや他イベント領域への展開は将来的な可能性として残しますが、現時点の優先事項ではありません。

## Current Stage

現在は **Phase 1: Audience / Measurement** です。

実装済みの主な機能:

- 公開イベント一覧
- 月間カレンダー表示
- 日付、地域、ジャンル、キーワード、来日公演による絞り込み
- イベント詳細ページ
- アーティスト、月別、都道府県、ジャンル、会場、来日公演ページ
- チケット販売サイトと公式情報へのリンク
- YouTubeを使ったアーティスト発見導線
- イベント詳細ページからの関連ライブ導線
- `/admin/candidates` による候補イベント確認
- `/admin/events` による公開イベント管理
- 本番環境の管理画面と管理APIのBasic認証
- GitHub Actions による半自動の候補イベント収集
- GA4によるページビュー計測
- チケットリンク、公式リンクへの外部遷移計測
- `ticketLinks` による販売元別チケットリンクのデータモデル
- Search Console レポート生成ワークフロー

現在の優先事項:

- 役に立つ検索流入を増やす
- イベント情報の網羅性と鮮度を上げる
- モバイルとカレンダーでライブを探しやすくする
- ユーザーがイベント詳細からチケット販売サイトや公式情報へ進んだか測定する
- 利用者数と送客価値が見えるまで、過度な収益化はしない

## Milestone Gates

このロードマップは日付ではなく、ユーザー行動によって次の段階へ進めます。

最も重要な商業化前の指標は次です。

**Monthly Ticket Outbound**: Metals Calendar からチケット販売サイトへ送った月間クリック数。

ページビューだけよりも、ライブに興味を持ったユーザーをチケット購入行動に近い場所へ送れているかを示せるため、Metals Calendar に合っています。

以下の数値は厳密な事業予測ではなく、判断をしやすくするための目安です。

| 段階 | MAU目安 | Monthly Ticket Outbound | やること |
| --- | ---: | ---: | --- |
| 現在 | 〜3,000 | 〜300 | GA4計測、SEO、イベント網羅性、UXを改善する |
| 最初の収益化 | 3,000〜5,000 | 300〜500 | 対応可能なチケットアフィリエイトを小さく試す |
| 業界接点 | 5,000〜10,000 | 500〜1,000 | アーティスト、事務所、プロモーター、レーベルへ画像や素材利用の相談を始める |
| 広告実験 | 10,000〜20,000 | 1,000〜2,000 | Featured Live などの明示的なスポンサー枠を試す |
| 遠征収益化 | 10,000〜30,000 | 2,000+ | ホテルや交通など、遠征文脈のアフィリエイトを検討する |
| 本格営業 | 30,000+ | 3,000〜5,000+ | プロモーター、レーベル、会場、フェスへ送客実績をもとに営業する |

チケット送客の目安:

- 100/月: ライブ発見に使われ始めている
- 500/月: チケットアフィリエイトを試す価値がある
- 1,000/月: 業界に送客価値を説明しやすくなる
- 2,000/月: スポンサー掲載の小さな実験が現実的になる
- 5,000/月: スポンサーやプロモーターへの提案を本格的に考えられる
- 10,000/月: メタルライブへの送客メディアとしてかなり面白い状態になる

これらの数字に到達したらすぐ収益化する、という意味ではありません。小さく測定可能な実験を始めるだけの材料が揃った、という判断基準です。

## Roadmap

### Phase 1: Audience / Measurement

#### 目的

利用者を増やし、Metals Calendar がライブ発見とチケット・公式情報への送客に貢献しているかを測定できる状態にします。

この段階が必要なのは、利用者と送客の証拠がないまま収益化や提携を進めても説得力が弱いためです。

#### 現在の状況

進行中です。

実装済み:

- 検索可能なイベント一覧と月間カレンダー
- 個別イベントページと関連ライブ導線
- アーティスト、月別、都道府県、ジャンル、会場、来日公演のSEOページ
- GA4ページビュー計測
- チケット・公式リンクの外部遷移計測
- Search Console レポート生成ワークフロー
- 自動公開しない候補イベント確認フロー
- 候補・公開イベント管理画面の保護

次にやること:

- Search Console のクエリと表示回数をもとに検索ランディングページを改善する
- モバイルでのイベント発見、特にカレンダーと一覧の見やすさを改善する
- 直近3か月のイベント網羅性と鮮度を上げる
- チケット・公式リンクの外部遷移データを継続して集める
- 複数販売元がある公演から段階的に `ticketLinks` を整える
- 実利用データが溜まったらページ速度とCore Web Vitalsを確認する
- 1人運用で維持できる範囲に管理・候補確認フローを保つ

#### 指標

- DAU / MAU
- Organic Search の表示回数とクリック数
- イベント詳細ページ閲覧数
- チケット販売サイトへの遷移数
- イベントページ・一覧からのチケットCTR
- 公式情報への遷移数
- 再訪率

主な計測元:

- Google Search Console
- GA4
- Vercel Analytics

#### 次のPhaseへ進む判断基準

- チケット遷移が安定して測定できている
- Monthly Ticket Outbound が 300〜500 に近づく、または超える
- どのイベント、アーティスト、ページ、販売元が行動につながっているか見える
- 複数販売元のチケットリンクを、カードを騒がしくせず扱える

### Phase 2: Ticket Monetization

#### 目的

Metals Calendar がチケット送客価値を示せるようになってから、チケットアフィリエイトを導入します。

目的は短期収益だけではありません。どのイベント、アーティスト、地域、販売元に送客できているかを把握することが重要です。

#### やること

- 利用可能なチケット販売サービスのアフィリエイト・提携制度を調べる
- 通常URLとアフィリエイトURLを別に持つ
- 信頼性や使いやすさを損なわない範囲でアフィリエイトリンクを使う
- 必要に応じてアフィリエイトリンクであることを明示する
- GA4で販売元別のチケットクリックを計測する
- 複数販売元がある公演でもイベントカードを騒がしくしない
- 報酬よりも、公式推奨、在庫確認、ユーザーの分かりやすさを優先する

データモデルの方向性:

- `ticketLinks[].provider`
- `ticketLinks[].url`
- `ticketLinks[].affiliateUrl`
- `ticketLinks[].price`
- `ticketLinks[].saleStartsAt`
- `ticketLinks[].saleStatus`
- `ticketLinks[].saleEndsAt`
- `ticketLinks[].priority`
- `imageUrl`
- `organizerName`
- `organizerUrl`

#### 指標

- 販売元別チケット遷移数
- イベントページ別チケットCTR
- イベントカードからのチケットCTR
- チケット遷移を生むイベントとアーティスト
- アフィリエイトリンクと通常リンクのクリック比率

#### 次のPhaseへ進む判断基準

- チケット送客データをもとに、業界関係者へ価値を説明できる
- Monthly Ticket Outbound が 1,000〜2,000 に近づく、または超える
- アフィリエイトを入れても、広告色が強すぎるサイトにならない

### Phase 3: Advertising / Promotion

#### 目的

十分な利用者と送客価値が見えた段階で、プロモーション枠を検討します。

広告は、ライブ検索・発見サービスとしての使いやすさを損なわないことを最優先にします。

#### やること

- 小さく、明確にラベル付けされたプロモーション枠を設計する
- 形式候補:
  - Featured Live
  - Featured Artist
  - トップページ掲載
  - 特定期間のイベントプロモーション
  - Sponsored コンテンツやガイド
- スポンサー掲載であることを明確に示す
- 通常のイベントを有料掲載の陰に隠さない
- スポンサー枠のクリックとその後の行動を通常導線と分けて測定する

想定顧客:

- アーティスト
- プロモーター
- レーベル
- ライブハウス
- フェス・イベント主催者

#### 指標

- スポンサー枠の表示回数
- スポンサー枠のクリック数
- スポンサーイベントの詳細閲覧数
- スポンサー枠経由のチケット・公式リンク遷移数
- スポンサー表示後の通常コンテンツ利用への影響

#### 次のPhaseへ進む判断基準

- 信頼性、検索性、イベント閲覧体験を損なわずに掲載できる
- スポンサーに提示できる利用データがある
- 表示、詳細閲覧、クリック、チケット遷移までの流れを測定できる

### Phase 4: Affiliate Expansion

#### 目的

ライブ遠征と相性の良いホテル・交通などのアフィリエイトを、自然な文脈があるページで検討します。

このPhaseは「このライブへ行くために必要な情報」を補うためのものです。単に広告を増やすことが目的ではありません。

#### やること

- 地方公演、フェス、複数日イベントなど、遠征需要がありそうなページを優先する
- すべてのイベントに旅行リンクを出すような実装は避ける
- 公式イベント情報とは分けて表示する
- チケットクリックとは別に計測する

#### 指標

- 遠征関連リンクの表示回数とクリック数
- 地域、フェス、会場ページからのクリック数
- チケットCTRやイベント詳細閲覧への影響

#### 次のPhaseへ進む判断基準

- 実際のユーザー行動にとって自然で役に立つ
- イベント発見やチケット確認の邪魔にならない
- Monthly Ticket Outbound が十分にあり、遠征需要がありそうなページを判断できる

### Phase 5: Artist / Industry Partnerships

#### 目的

アーティスト、レーベル、プロモーター、会場、イベント主催者との関係を作り、より正確なイベント情報や正式に許可された素材を掲載できる状態を目指します。

公式素材を使えると、権利上安全にサイトの見た目と有用性を上げられます。

#### やること

- イベント掲載依頼を受ける軽い手順を作る
- 主催者側から必要な情報を明確にする
- 利用許諾を得た素材の掲載を検討する
  - 公式アーティスト写真
  - 公演フライヤー
  - プレス素材
  - アーティストプロフィール
  - 主催者からの更新情報
- 公開前の人間レビューは維持する
- 権利確認できない画像は保存・利用しない

#### 指標

- 権利者・主催者から提供されたイベント数
- 許可済み素材の数
- パートナー提供の更新情報を反映する速さ
- パートナーサイトへの送客数

#### 次のPhaseへ進む判断基準

- 提供情報や素材がサイト価値の実用的な源泉になる
- レビュー運用が重くなりすぎず、1人運用で回せる

### Phase 6: Event Discovery

#### 目的

Metals Calendar を「検索するサイト」から「知らなかったライブに出会えるサービス」へ進化させます。

目標は「知らなかったライブを見つけて、行きたくなる」体験です。

#### やること

- お気に入りアーティスト
- お気に入りジャンル
- お気に入り地域
- 今週末、近くで行けるライブ
- 関連アーティスト、共演者からの発見
- おすすめライブ
- 通知やフィード
- 実際の行動データにもとづくランキング
- 十分なデータとプライバシー方針ができた後のパーソナライズ

#### 指標

- 発見モジュールのクリック数
- 関連・おすすめ導線からのイベント詳細閲覧数
- 再訪率
- 発見導線後のチケット・公式リンク遷移数
- アーティスト、ジャンル、地域、会場ページへの再訪

#### 長期的な達成サイン

ユーザーが既知のアーティストを検索するときだけでなく、「何か行けるライブを探したい」ときにも Metals Calendar に戻ってくること。

コア指標:

- DAU / MAU
- Organic Search 表示回数
- Organic Search クリック数
- インデックス登録ページ数
- イベント詳細ページ閲覧数
- チケット販売サイトへの遷移数
- Ticket CTR
- 公式サイトへの遷移数
- 再訪率

運用指標:

- レビュー待ち候補イベント数
- イベント情報の鮮度
- 直近3か月の網羅性
- 公式発表から候補作成までの時間
- 候補作成から公開までの時間

商業化準備指標:

- 販売元別チケットクリック数
- イベント別チケットクリック数
- アーティスト別チケットクリック数
- 地域・会場別チケットクリック数
- アフィリエイトリンクと通常リンクのクリック傾向

## Long-Term Direction

長期的には、次の仕組みを構造化してつなげます。

- イベントデータ収集
- Artist / Event / Venue / Ticket の構造化
- 検索
- Discovery
- Recommendation
- Analytics
- Ticket Conversion
- Monetization

当面の焦点は狭く保ちます。まずは Metals Calendar を、日本のメタル・ラウド系ライブを探すための実用的な場所にします。

他ジャンルや他イベント領域への展開は、Metals Calendar のモデルが有用で、維持可能で、測定可能だと分かってから検討します。

## Product Principles

- 公開前の最終判断は人間が行う
- 網羅性と鮮度は重要だが、明らかな誤情報を載せない
- 公式情報と信頼できる情報源を優先する
- 短期収益よりユーザーの信頼を優先する
- スポンサーやアフィリエイトは分かりやすく表示する
- 1人で運用できる状態を保つ
- 仕組みは、作業量を減らすか明確なユーザー価値を作るときだけ追加する
