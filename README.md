# metal-live-schedule
Japan metal live events calndar with filters

# 要件
- カレンダーで見る
- 地域/ジャンルで絞り込み可能
- チケットURL に飛べる

# イベント型
- artist
- date
- venue # 会場
- prefecture
- genres
- ticketUrl
- officialUrl
- status
